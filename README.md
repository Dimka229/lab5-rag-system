# Лабораторная работа №5: RAG-система вопросов и ответов по документам

**Дисциплина:** Прикладные задачи искусственного интеллекта  
**Вариант:** 1 (Локальные нормативные акты вуза)

## Описание задачи
Построена система генерации с дополненным поиском (RAG). Система принимает вопрос на естественном языке, находит релевантные фрагменты в корпусе документов и генерирует ответ с указанием источника.

## Корпус
Использованы 3 документа (имитация нормативных актов): Положение о практике, Положение о ВКР, Положение о текущем контроле.

## Результаты поиска
| Конфигурация | Recall@5 | MRR |
| :--- | :--- | :--- |
| Векторный | 1.0 | 0.4815 |
| BM25 (лексический) | 1.0 | 0.8148 |
| **Гибридный (RRF)** | **1.0** | **1.0** |

## Модели
*   **Эмбеддинги:** `intfloat/multilingual-e5-small` (для поиска).
*   **Генерация:** `Qwen/Qwen2.5-1.5B-Instruct` (локально, без API).

## Артефакты
*   `lab5_RAG.ipynb` — ноутбук со всеми шагами (индексация, поиск, генерация).
*   `questions.csv` — тестовый набор вопросов (40 шт., 5 без ответа).
*   `corpus/` — текстовые файлы документов.

## Интерфейс
Реализован чат на Gradio, который показывает ответ и найденный контекст для проверки обоснованности.
